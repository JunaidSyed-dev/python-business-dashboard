# 📊 Python Business Dashboard

A Python-based business data analysis and visualization project that explores monthly revenue, expenses, profit, and customer growth using **Pandas, NumPy, and Matplotlib**.

The project creates a six-chart business dashboard from a sample dataset covering 12 months of company performance.

## 📌 Features

The dashboard visualizes:

* 📈 Monthly revenue trend
* 💰 Monthly expense trend
* ⚖️ Revenue vs. expenses comparison
* 📊 Monthly profit
* 👥 Customer growth
* 📉 Revenue distribution

## 🛠️ Technologies Used

* **Python**
* **Pandas** — data manipulation and analysis
* **NumPy** — numerical operations
* **Matplotlib** — data visualization

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/python-business-dashboard.git
```

### 2. Navigate to the project

```bash
cd python-business-dashboard
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the project

```bash
python business_dashboard.py
```

The program will generate the business dashboard and save it as:

```text
company_dashboard.png
```

## 📊 Analysis

The dataset contains monthly information for:

* Revenue
* Expenses
* Customers

Profit is calculated using:

```text
Profit = Revenue - Expenses
```

The visualizations make it easier to identify trends in business performance over the year.
